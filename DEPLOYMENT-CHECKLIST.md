# Checklist sebelum EduSpace dipublikasikan

- [ ] Firebase project dibuat.
- [ ] Authentication Email/Password diaktifkan.
- [ ] Firestore Database dibuat.
- [ ] `firebase-config.js` dibuat dan diisi dengan konfigurasi project.
- [ ] Firestore Security Rules dipublikasikan.
- [ ] Cloud Functions dependencies di-install.
- [ ] Cloud Function `gradeAssignment` berhasil di-deploy.
- [ ] Domain `USERNAME.github.io` ditambahkan ke Authorized domains Firebase.
- [ ] Seluruh file proyek di-upload ke root repository GitHub.
- [ ] GitHub Pages diaktifkan dari branch `main`, folder `/ (root)`.
- [ ] Tes akun guru, akun siswa, pembuatan kelas, join kelas, materi, ujian, chat, meeting, dan nilai.
- [ ] Tautan live website di README diganti dengan URL sebenarnya.
- [ ] Kebijakan privasi dan persetujuan penggunaan untuk siswa disiapkan oleh sekolah.
